# AutoLead AI

Веб-приложение для поиска и обогащения B2B-лидов. Интерфейс работает на Vite/React, API — на Express. В production обязательна PostgreSQL.

## Локальный запуск

Требуется Node.js 20 или новее.

1. Установите зависимости: `npm install`.
2. Создайте файл `.env` в корне проекта.
3. Добавьте настройки:

```dotenv
JWT_SECRET=replace-with-a-random-secret-of-at-least-32-characters
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=replace-with-a-unique-password-at-least-12-characters
DATABASE_URL=postgresql://...
TAVILY_API_KEY=
FIRECRAWL_API_KEY=
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.8-flash
ALLOWED_ORIGINS=http://localhost:5173
VITE_API_URL=http://localhost:3001
```

`JWT_SECRET` обязателен при каждом запуске. `ADMIN_EMAIL` и `ADMIN_PASSWORD` нужны только при первом запуске, если база пользователей пуста. Для последующих запусков используйте ту же базу данных или сохранённый файл `users.json`.

Для локальной проверки `DATABASE_URL` можно не задавать: приложение использует JSON-файлы. В production (включая Railway) без `DATABASE_URL` сервер намеренно не запускается. Если нужно разово перенести данные из JSON в пустую или уже работающую PostgreSQL, установите `IMPORT_JSON_SEED=true` на один запуск. Импорт только добавляет отсутствующие записи и настройки, не обновляет существующие; после успешного импорта обязательно удалите переменную. Повторный импорт не выполняется благодаря маркеру в таблице `settings`.

4. Запустите API в одном терминале: `npm run start`.
5. Запустите интерфейс во втором терминале: `npm run dev`.

Откройте URL, напечатанный Vite (обычно `http://localhost:5173`). Не добавляйте `.env` в Git.

## Проверки перед выпуском

`npm run typecheck` проверяет TypeScript фронтенда и API, `npm test` запускает unit-тесты, `npm run build` собирает фронтенд. Эти три команды запускаются в GitHub Actions при push и pull request. `/api/health` проверяет доступность процесса, а `/api/ready` дополнительно требует PostgreSQL и ключи Tavily, Firecrawl и LLM.

Вход ограничен по IP и сочетанию IP/email. Повторная проверка лида запускается фоновой задачей, ограничена по частоте и числу одновременных запусков. Настройки поставщика и скоринга доступны только администраторам.

## Сторонние сервисы

Поиск использует Tavily, анализ сайтов — Firecrawl, AI-обогащение — Gemini. КП формируется быстрым HTML-шаблоном из карточки поставщика и совпавших позиций каталога; Gemini для генерации КП не вызывается. Геокодирование выполняется через Nominatim.

## Карточка поставщика и предложение

В разделе «Поставщик» укажите реквизиты, контакты, оплату, доставку, гарантию и текст предложения. Каталог можно загрузить в CSV или JSON. Для CSV обязательны колонки `brand`, `name`, `price`; `sku`, `car` и `stock` необязательны. Скачайте шаблон в приложении.

Совпадение брендов сайта с загруженным каталогом участвует в весе скоринга «Совпадение с ассортиментом». После сохранения профиля скоринг уже найденных лидов пересчитывается. КП создаётся по кнопке в карточке выбранного лида и сохраняется в HTML.


## Импорт лидов из CSV

В разделе «Работа с лидами» нажмите «Импорт CSV», выберите файл и проверьте предпросмотр. Новые записи получают скоринг по текущим настройкам и предложению поставщика. Сначала проверьте список новых строк, дублей и ошибок, затем нажмите «Импортировать». Повторные компании отсеиваются по домену, а если сайт не указан — по нормализованному названию компании и городу. Импортированные координаты показываются на карте.

Шаблон доступен прямо в приложении. Минимально нужна колонка `Компания` (также поддерживается `company_name`). Дополнительные колонки: `Сайт`, `Город`, `Вид деятельности`, `Адрес`, `Телефон`, `Email`, `Бренды`, `ЛПР`, `Должность`, `Широта`, `Долгота`. Поддерживаются разделители запятая, точка с запятой и табуляция. Максимум — 1000 строк за файл. В карточке лида можно исправить реквизиты компании, контакты и бренды; при изменении контактов или брендов скоринг пересчитывается.


В таблице лидов отображается воронка менеджера: «Новый» → «В работе» → «КП подготовлено» → «КП отправлено» → «Клиент». После успешной генерации КП лид со статусом «Новый» или «В работе» автоматически переходит в «КП подготовлено»; остальные статусы не меняются. Количество лидов по этапам можно открыть нажатием; «Не целевой» и «Чёрный список» вынесены отдельно.

На карте можно фильтровать лиды по городу, виду деятельности и статусу. Во всплывающей карточке метки показываются контакты и текущий этап лида.

На карте можно запросить поиск координат для выбранных лидов без меток. Геокодер использует адрес, название компании и город; если точную точку не удаётся определить, координаты не подменяются центром города. Сектор создаётся прямоугольником (2 клика), кругом (центр и край) или замкнутой ломаной-областью (от 3 вершин). При сохранении задаются название, менеджер и цвет; лиды внутри сектора назначаются ответственному.
